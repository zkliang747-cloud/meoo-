## 4. 关键代码片段

### 4.1 polishAnswer 提示词

```javascript
const prompt = `
你是一位温和的回忆录编辑。请润色下面这段口述回答，输出仅包含润色后的文字。

要求：
1. 忠于原意，不添加用户没说的事实
2. 保留口语风格，但删除口头禅和重复
3. 如果原文中提到之前出现的人物或事件，请用一句括号提示关联，如"（还记得那位王师傅吗？）"
4. 段落清晰，每段3-5句
5. 不要过度煽情，不用感叹号

问题：${question}
用户原话：${transcript}
前情摘要：${summary}
`;
```

### 4.2 语音识别调用

```javascript
// 使用百度语音识别API
const recognizeVoice = async (audioBuffer) => {
  const response = await fetch('https://vop.baidu.com/server_api', {
    method: 'POST',
    headers: {
      'Content-Type': 'audio/wav;rate=16000',
    },
    body: audioBuffer
  });
  const data = await response.json();
  return data.result[0]; // 识别文本
};
```

### 4.3 有声H5生成逻辑

```javascript
// 云函数内
exports.generateH5 = async (event) => {
  const { projectId } = event;
  
  // 1. 拉取项目数据
  const project = await db.collection('projects').doc(projectId).get();
  const answers = await db.collection('answers')
    .where({ projectId })
    .orderBy('createdAt', 'asc')
    .get();
  
  // 2. 渲染HTML模板
  const html = renderTemplate({ project, answers });
  
  // 3. 上传到云存储
  const fileId = await cloud.uploadFile({
    cloudPath: `h5/${projectId}.html`,
    fileContent: Buffer.from(html)
  });
  
  // 4. 获取临时链接
  const url = await cloud.getTempFileURL({ fileList: [fileId] });
  
  return { h5Url: url.fileList[0].tempFileURL };
};
```

## 6. 安全与性能

### 6.1 数据安全
- 所有敏感操作需校验openId
- 数据库规则：用户只能读写自己的数据
- 录音文件URL设置有效期（1小时）

### 6.2 性能优化
- 录音分段上传（每30秒）
- 图片压缩后上传（最大2MB）
- 云函数超时设置：30秒
- 前端缓存问题列表

### 6.3 降级方案
- 语音识别失败 → 提示手动输入
- AI润色超时 → 保留原文，提示稍后重试
- 支付失败 → 保存订单，24小时内可恢复
